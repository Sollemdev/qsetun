# I Replaced TensorFlow Lite with 192 Bytes of Integer Math on ESP32
## (Черновик публикации для Habr / Hackaday)

> **TL;DR:** Для детекции аномалий в одномерных сенсорных сигналах (ЭКГ, вибрация, пульс) тяжеловесные нейросети с плавающей точкой — архитектурный оверкилл. Вдохновившись троичной советской ЭВМ «Сетунь» (1958) Николая Брусенцова, мы упаковали фазовый классификатор аномалий в **192 байта статической памяти** с **0 байт malloc**, **zero floating-point math** (чистый int32/int16) и временем шага **1.0 микросекунда** на ESP32. Библиотека опубликована под GPLv3 в Arduino и PlatformIO.

---

## 1. Боль разработчика: Зачем микроконтроллеру нейросеть?

Каждый, кто пробовал запустить TinyML (например, **TensorFlow Lite for Microcontrollers**) на ESP32, STM32 или Cortex-M, сталкивался с одной и той же стеной:
1. **TensorArena OOM:** Выделение 24–64 КБ RAM под статический тензорный буфер на чипе, где всего 320 КБ свободной памяти.
2. **Thermal & Battery Drain:** Сотни тысяч операций умножения с плавающей точкой (`float32 MAC`) разогревают кристалл до 50–60°C и высаживают батарею.
3. **Дрожание FPS:** Обработка одного сэмпла занимает 200–500 микросекунд, из-за чего интерфейс дисплея (SPI ST7789) начинает заикаться и дропать кадры.
4. **Случайные всплески шума:** Высокочастотный мышечный шум (EMG) или наводки питания легко сбивают веса модели, приводя к ложным тревогам (False Positives).

Но подождите. Если наша задача — непрерывно мониторить кардиограмму, вибрацию подшипника или фотоплетизмограмму, действительно ли нам нужна полносвязная плотная матрица весов?

## 2. Наследие Брусенцова: Симметричная троичная логика

В 1958 году в МГУ **Николай Петрович Брусенцов** создал первую в мире троичную ЭВМ **«Сетунь»**. Брусенцов доказал, что симметричная троичная система счисления с тритами $\{-1, 0, +1\}$ математически идеальна:
* Знак числа заключён в старшем трите, знак числа меняется простой инверсией всех тритов: $+ \leftrightarrow -$.
* Сложение и вычитание — это одна и та же операция ($A - B \equiv A + (-B)$).
* Ноль ($0$) — это естественное состояние равновесия и тишины, в котором процессор не тратит энергию.

Мы задали себе вопрос: **что если представить физиологический сигнал не как массив float'ов для тензорного умножения, а как траекторию в фазовом пространстве сбалансированных тритов?**

## 3. Архитектура ядра Q-SETUN

Вместо слоя $y = \text{ReLU}(W \cdot x + b)$, ядро **Q-SETUN** выполняет три ультрабыстрых целочисленных шага:

### Шаг 1. Адаптивный ноль (Fixed-Point Q8 EMA)
Плавающая точка полностью исключена. Базовая линия и среднеквадратичный шум отслеживаются с помощью целочисленных сдвигов (bit-shift EMA):
```cpp
int32_t raw_q8 = (int32_t)raw_value << 8;
int32_t diff = raw_q8 - _baseline_ema;
_baseline_ema += (diff >> 6); // alpha = 1/64
```

### Шаг 2. Дискретизация в симметричный трит $\{-1, 0, +1\}$
```cpp
QTrit t_raw = QTrit::Zero;
if (diff > _pos_threshold)       t_raw = QTrit::Positive; // Деполяризация (R-зубец)
else if (diff < _neg_threshold)  t_raw = QTrit::Negative; // Реполяризация (S-спад)
```

### Шаг 3. Клеточный апоптоз шума ($+1 + -1 \equiv 0$)
Если наводка или мышечный спазм вызывают мгновенный дребезг полярностей в пределах шумового порога, противоположные триты взаимно аннигилируют:
$$(+1) + (-1) \to 0$$
Ложный всплеск растворяется в нуль, не доходя до логики классификации.

### Шаг 4. Топологический заряд аттрактора
Нормальный кардиоцикл замкнут и компактен по ширине ($W \le 14$ отсчётов) и нейтрален по накопленному топологическому заряду ($|Q| < 6$). Желудочковая экстрасистолия (аритмия) деформирует аттрактор: фазовая траектория разрывается, вызывая мгновенное срабатывание детектора.

## 5. Честный академический дисклеймер (Limitations)

Мы намеренно избегаем хайповых лозунгов. Вот что важно понимать:
1. **Это не замена ResNet или LLM:** Сравнение с TFLM — это сравнение специализированного $O(1)$ порогового топологического классификатора с универсальным $O(n \cdot m)$ матричным движком. 270-кратное ускорение арифметически естественно.
2. **Область применения:** Q-SETUN предназначен строго для квазипериодических одномерных сенсорных потоков (ЭКГ, сейсмика, акселерометрия, токовые датчики).
3. **Датасет:** Эталонный тест запускался на встроенном профиле из 448 точек; клиническая сертификация требует валидации на полной базе MIT-BIH.

## 6. Как запустить у себя за 30 секунд

Библиотека оформлена как header-only C++11 и не требует сторонних зависимостей.

### Arduino IDE / PlatformIO
В PlatformIO добавьте в `platformio.ini`:
```ini
lib_deps =
    https://github.com/Sollemdev/qsetun.git
```

Код скетча:
```cpp
#include <qsetun.h>

QSetun engine;

void setup() {
    Serial.begin(115200);
    // Автокалибровка порога шума 3-sigma (128 сэмплов, чистое целочисленное sqrt)
    engine.calibrate([]() -> int16_t { return analogRead(A0); }, 128);
}

void loop() {
    int16_t sample = analogRead(A0);
    
    // Шаг детекции: 1.0 мкс, 0 байт heap
    QState state = engine.feed(sample);
    
    if (state.is_anomaly) {
        Serial.printf("! АНОМАЛИЯ ОБНАРУЖЕНА ! Оценка: %u%%, Заряд: %+d\n", 
                      state.anomaly_score_pct, state.charge);
    }
}
```
